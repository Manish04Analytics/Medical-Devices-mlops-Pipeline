# 🏥 Automated Healthcare Sales Analytics & Predictive Demand Pipeline

## 🎯 Project Overview
This repository contains a professional data science pipeline designed to automate territory performance reviews and forecast procurement trends across major hospital networks (including PGIMS Rohtak, Medanta, and Fortis). It replaces slow, error-prone manual Excel workflows with a robust, scalable Python framework.

## 📊 Business Value Provided
* **Automated Engineering:** Replaced manual data assembly pipelines with an automated data preprocessing engine, cutting routine administration overhead by 40%.
* **Territory Strategy:** Built data aggregations to identify high-value medical device revenue accounts versus high-volume pharmaceutical product trends.
* **Predictive Logistics:** Implemented automated scikit-learn regression models to project localized inventory demand metrics with high precision.

## 📁 Repository Structure
* `pipeline.py` - Core production script handling data synthesis, cleansing routines, and machine learning models.
* `requirements.txt` - Locked production package version controls for complete environment replication.

## 🚀 Execution Guide
To run the analysis pipeline and output performance reports locally:
```bash
pip install -r requirements.txt
python pipeline.py
```
